Attack-path readout

An autonomous validation platform confirms which attack paths into a network actually work. This build takes each confirmed path at a made-up electric utility, has a Claude agent write the fix ticket for the team that can break it, holds anything that reaches a crown-jewel system for a person, tracks the retests, and rolls it all into the weekly readout for security leadership.

Run it yourself

Python 3.10 or later. Tests and the rules-only baseline need no key; the agent needs ANTHROPIC_API_KEY.

python3 -m unittest
python3 -m readout.run --agent template --out runs/template
python3 -m readout.run --agent claude --out runs/mine
